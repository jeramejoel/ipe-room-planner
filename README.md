# Ipe Room Planner

Interactive 3D plan for a black music room: floating ipe slat walls with back-lit LEDs,
a double-walled control / vocal booth with a long double window and a sound-lock door,
draped fabric ceiling and layered rugs.

Open `index.html` in any browser, or visit the GitHub Pages link.

- Tap a wall chip for a flat elevation and its cut sheet
- Controls: panel heights, lighting scenes, LED color and dimmer, diffuser and absorber swaps
- Build guide: order of work, materials, and step-by-step builds for every piece

Where the numbers come from:

- Measured on site 2026-11-15: the north wall at 239", and the overhang at 65" wide,
  16" deep, underside 5' 0".
- Still assumed: stud positions, the obstacle positions, and the 97" ipe stock length
  the whole buy is packed onto. Confirm the stock length with the supplier before
  ordering, because the main band is cut at 96" and an 8 ft board will not give it.
